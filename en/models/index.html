GPT-5.4

OpenAI · Released 2026.03.05

GPT-5.4 is OpenAI's latest flagship model, featuring Standard, GPT-5.4 Thinking (focused on deep reasoning), and GPT-5.4 Pro (API max performance). Integrated with GPT-5.3-Codex for code generation and Computer Use support, it excels in coding, reasoning, and professional workflows.

Context Window 256K tokens
Multimodality Text / Image / Audio
Key Strengths Thinking 推理 · Computer Use · Codex 集成
API Pricing $2.50 / 1M input · $10.00 / 1M output
Use Cases Complex reasoning · Coding · Planning tasks · Professional workflow
🎭

Claude Sonnet 4.6

Anthropic · Released 2026.02.17

Claude Sonnet 4.6 strikes the perfect balance between speed and intelligence, making it the top choice for daily tasks. Enhanced coding and Computer Use make it a developer favorite. The Claude Opus 4.6 is Anthropic's most powerful model for complex Agent tasks and long-term planning.

Context Window 1M tokens (Beta)
Multimodality Text / Image / Visual
Key Strengths Computer Use · Agentic 能力 · 代码精度 · 安全对齐
API Pricing $3.00 / 1M input · $15.00 / 1M output
Use Cases Agent workflows · Large codebases · Long doc analysis · Security-sensitive
✨

Gemini 3.1 Pro

Google DeepMind · Released 2026.02.19

Gemini 3.1 Pro is Google's latest complex problem solver, with native support for text, image, audio, video, and code multimodal reasoning. With an industry-leading 2M context window, and Gemini 3.1 Flash-Lite featuring innovative Thinking Levels to adjust reasoning depth.

Context Window 2M tokens
Multimodality Text / Image / Audio / 视频 / 代码（全模态）
Key Strengths 超长Context · Thinking Levels · 全模态原生 · 搜索整合
API Pricing $1.25 / 1M input · $5.00 / 1M output
Use Cases Ultra-long docs processing · Video analysis · Multimodal chat · Enterprise search
